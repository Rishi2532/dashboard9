Chatbot Query Resolution Priority
Priority 1: Keyword/Widget Matching ⚡ (FASTEST)
When: User query matches exact keywords like "optimal chlorine", "fully completed schemes", "above 55 lpcd", etc.
How: Direct keyword detection using toLowerCase() and includes()
Response Time: Instant (no AI API call)
Example: "Show me villages with water" → Triggers VillagesWithWaterWidget
Benefit: Fast, predictable, widget-based responses with interactive UI
Priority 2: Enhanced Intent Detection 🎯 (STRUCTURED)
When: Query doesn't match keywords but has structured intent with entities
How: OpenAI analyzes and extracts intent + entities (region, scheme, village names)
Response Time: ~1-2 seconds (one OpenAI API call)
Example: "Show me comprehensive analysis for scheme 7940695" → Triggers COMPREHENSIVE_SCHEME_ANALYSIS intent
Benefit: Handles complex structured queries with entity extraction
Priority 3: Text-to-SQL Fallback 🔍 (FLEXIBLE - NEW!)
When: Query doesn't match keywords OR enhanced intents
How: OpenAI receives full database schema, generates SQL, executes query, formats response
Response Time: ~2-3 seconds (OpenAI generates SQL + database execution)
Example: "Which region has the most flow meters?" → Generates SQL → Returns conversational answer
Benefit: Handles ANY question about the database, unlimited flexibility
