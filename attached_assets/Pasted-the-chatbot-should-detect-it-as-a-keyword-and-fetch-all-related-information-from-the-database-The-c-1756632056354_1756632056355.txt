Scheme Information (from scheme_status table):

Region the scheme belongs to.

Completion status:

If fully_completion_scheme_status = "Completed" → show as Fully Completed.

If fully_completion_scheme_status = "In Progress" → show as In Progress.

Number of villages in the scheme (number_of_village).

Number of villages integrated (total_villages_integrated).

Number of fully completed villages (fully_completed_villages).

Number of partial villages (partial_villages).

Number of ESR in scheme (total_number_ofesr).

Number of ESR integrated (total_esr_integrated).

Number of fully completed ESR (no_fully_completed_esr).

Number of meters, residual chlorine analyzers, and pressure transmitters (flow_meters_connected, residual_chlorine_analysers_connnected, pressure_transmitters_connected).

Village Water Supply Data (from water_scheme_data table):

Villages receiving water = count of villages where water_value_day7 > 0.

Villages with no water = count of villages where water_value_day7 = 0.

Villages with consistent water supply = count of villages where all water_value_day1 → water_value_day7 > 0.

Villages with consistent zero water = count where all water_value_day1 → water_value_day7 = 0.

Villages with above 55 LPCD = count where lpcd_value_day7 > 55.

Villages with below 55 LPCD = count where lpcd_value_day7 < 55.

Villages consistently above 55 LPCD = count where all lpcd_value_day1 → lpcd_value_day7 > 55.

Villages consistently below 55 LPCD = count where all lpcd_value_day1 → lpcd_value_day7 < 55.

Sensor Data (from chlorine_table and pressure_table):

For chlorine sensors (chlorine_value_day7):

Optimal range = 0.2 – 0.5

Below = < 0.2

Above = > 0.5

For pressure sensors (pressure_value_day7):

Optimal range = 0.2 – 0.7

Below = < 0.2

Above = > 0.7

Also calculate consistent ranges for chlorine and pressure:

Consistent Optimal = all 7 days within optimal range.

Consistent Below = all 7 days below range.

Consistent Above = all 7 days above range.
