🔎 Query Handling Rules

Detect Keyword:

If a user’s sentence contains any of the above keywords (case-insensitive, allow partial match), treat that as the main query type.

Scope Detection:

All Regions → If only keyword is present (e.g., "optimal chlorine", "below pressure everywhere") in a sentence no matter how long then fetch list from all regions.

Specific Region → If keyword + a known region/circle/division/subdivision/block name is present (e.g., "optimal chlorine from Nagpur") then fetch list for that region only.

Specific Scheme → If keyword + scheme name and/or scheme ID are present in the sentence (e.g., "optimal chlorine in 105 Villages RRWS" or "optimal chlorine in scheme 1234"), then fetch list for that scheme only.

To confirm scheme match: check that all words from scheme name (ignoring case/extra spaces) are found in the user’s query.

Output:

Display the relevant list of results based on detected keyword and scope.

If no valid match is found → ask user to clarify whether they want info by region or scheme. Example Queries and Expected Behavior

User: "optimal chlorine" → Show list of schemes/villages with optimal chlorine across all regions.

User: "optimal chlorine in Nagpur" → Show list for Nagpur region.

User: "optimal chlorine in 105 villages rrws" → Show list for scheme: 105 Villages RRWS.

User: "below 55 lpcd in scheme 9876" → Show list for scheme with ID 9876.

User: "consistent water in chandrapur" → Show list for Chandrapur region.
