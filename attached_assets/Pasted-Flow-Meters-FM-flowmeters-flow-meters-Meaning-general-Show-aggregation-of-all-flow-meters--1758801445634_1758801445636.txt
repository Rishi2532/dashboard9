Flow Meters (FM / flowmeters / flow meters)
Meaning (general): Show aggregation of all flow meters integrated.
Database Field:
•	region → flow_meter_integrated
•	scheme_status → flow_meters_connected (when scheme is mentioned)
Example:
•	User: “How many flow meters are there?” → Answer from: flow_meter_integrated (sum of all regions).
•	User: “Flow meters in Nagpur” → Answer from: flow_meter_integrated (Nagpur region).
•	User: “Flow meters in Bidgaon Tarodi WSS” → Answer from: scheme_status → flow_meters_connected (for that scheme).

🔹 ESR (Elevated Service Reservoir)
Meaning: Show ESR details either by scheme or region.
Database Field:
•	scheme_status → total_number_of_esr (for ESR in a scheme)
•	scheme_status → total_esr_integrated (for integrated ESR in a scheme)
•	region → total_esr_integrated (if asked generally)
•	region → fully_completed_esr (if fully completed ESR is asked)
Example:
•	User: “ESR in 20003791” → Answer from: total_number_of_esr.
•	User: “ESR integrated in Bidgaon Tarodi WSS” → Answer from: total_esr_integrated.
•	User: “ESR integrated in Nagpur” → Answer from: region → total_esr_integrated.
•	User: “Fully completed ESR in Nagpur” → Answer from: region → fully_completed_esr.
