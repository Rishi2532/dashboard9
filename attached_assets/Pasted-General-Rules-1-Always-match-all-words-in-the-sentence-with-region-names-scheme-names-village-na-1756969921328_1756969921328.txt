General Rules
1.	Always match all words in the sentence with region names, scheme names, village names, or IDs in the database.
2.	If both region and metric keyword are present, filter results for that region only.
3.	If no region/village/scheme specified, then show results for all regions combined.
4.	Handle both names (e.g., Nagpur, Bidgaon Tarodi WSS) and IDs (scheme_id, village_id).
5.	If a query has multiple possible matches, fetch exact matches only (not partial fuzzy matches).
